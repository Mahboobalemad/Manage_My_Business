# نظام إدارة نشاطي التجاري (Shops Management System)

نظام إداري ومحاسبي متكامل ومستقل لسطح المكتب (Desktop Application) مُصمم لإدارة الأنشطة التجارية والمحلات والفروع والتجار والموظفين والرواتب والتقرير المالية بدقة وسرعة، مع دعم كامل للعمل بدون إنترنت (100% Offline) باللغة العربية واختيارات متعددة للعملات والنسخ الاحتياطي.

---

## أبرز المميزات والوحدات الوظيفية

### 1. لوحة التحكم والإحصائيات الفورية (Dashboard)
* عرض مؤشرات الأداء الحية اليومية والشهرية (إجمالي المبيعات، المصروفات، صافي الأرباح).
* تتبع إجمالي ديون التجار المستحقة وإجمالي مستحقات رواتب الموظفين.
* فلترة ديناميكية سريعة حسب فرع محدد أو استعراض **"الكل (جميع المحلات)"**.

### 2. ادارة النشاط اليومي والمبيعات (Daily Activities & Expenses)
* تسجيل مبيعات ومصروفات كل فرع يومياً مع حماية ضد تكرار القيود لنفس اليوم.
* دعم تتبع صافي المبيعات وصافي الأرباح الاختياري بشكل مستقل.
* تبويب زمني شهري تفاعلي يتيح التنقل بين أشهر السنة بسهولة.

### 3. إدارة الفروع التجارية والمحلات (Branches Management)
* إضافة وتعديل واستعراض تفاصيل الفروع والمحلات التجارية.
* كشف حساب تفصيلي وشامل لكل فرع يوضح إجمالي المبيعات والمصروفات والأرباح وعدد الفواتير والموظفين.
* نظام أمان يمنع حذف الفروع المرتبطة بحركات مالية أو موظفين.

### 4. فواتير البضاعة وتوزيعها (Invoices & Allocations)
* تسجيل فواتير البضاعة المستلمة من الموردين وتوزيع الفاتورة الواحدة على عدة فروع بنسب أو مبالغ مخصصة.
* ربط تلقائي ومباشر مع حسابات التجار لخصم الدفعات وإعادة احتساب الرصيد المستحق فورياً.

### 5.  حسابات التجار والموردين (Traders & Suppliers Ledger)
* سجل تفصيلي لبيانات التجار مع تصنيف حالة الحساب (نشط / غير نشط).
* كشف حساب تفصيلي يوضح (إجمالي الفواتير له / إجمالي الدفعات عليه / المتبقي له أو عليه).
* تمييز رصيد التاجر بالألوان (الأخضر لـ "له" والأحمر لـ "عليه").

### 6. الموظفون والرواتب (Employees & Payroll)
* إدارة بيانات الموظفين والرواتب والروابط بالفروع والتصنيفات.
* كشف حساب مستقل لكل موظف يسجل سحبيات الموظف والخصومات والمكافآت وصافي المتبقي له أو عليه.
* تصفية الموظفين حسب محل تجاري معين أو جميع المحلات.

### 7. دفتر الزكاة المستقل (Zakat Management)
* نظام مستقل كلياً عن الحسابات التجارية لإدارة جداول ودفاتر الزكاة المنفقة.
* تسجيل مصارف وأبواب الزكاة بالتاريخ والنوع والمبالغ والملاحظات.

### 8. قسم إصدار التقارير المتقدمة (Reports & Export Engine)
* تقرير النشاط اليومي والمبيعات (مع فلترة الفروع والتاريخ).
* تقرير الفواتير المستلمة (فلترة حسب التاجر، الفترة، أو الفرع).
* كشوفات حساب تفصيلية للتاجر، للموظف، وللفرع.
* طباعة فورية وتصدير لمستندات تفاعلية بتنسيق راقٍ ومناسب لطباعة A4.

### 9. النسخ الاحتياطي واستعادة البيانات (Backup & Cloud Upload)
* جدولة النسخ الاحتياطي التلقائي (يومي / أسبوعي / شهري / سنوي).
* إنشاء نسخة احتياطية فورية تلقائية قبل تنفيذ أي عمليات حذف حيوية.
* إمكانية الرفع والربط السحابي المباشر عبر Google Drive.
* نظام أمان وتأكيد قبل استعادة البيانات لمنع الفقدان غير المقصود.

### 10.  إعدادات التطبيق وتفضيلات العملات (Application Settings)
* اختيار العملة المفضلة للتطبيق (`YER` ريال يمني / `SAR` ريال سعودي / `USD` دولار أمريكي).
* تخصيص جداول النسخ الاحتياطي والتفضيلات العامة.

## المعمارية والتقنيات البرمجية (Tech Stack & Architecture)

* **Language:** C# 13 (.NET 10.0)
* **Framework:** WPF (Windows Presentation Foundation) - RTL Support
* **Design Pattern:** MVVM (Model-View-ViewModel) + Clean Architecture
* **Database & ORM:** SQLite Embedded Database + Entity Framework Core 10 (`Microsoft.EntityFrameworkCore.Sqlite`)
* **Dependency Injection:** `Microsoft.Extensions.DependencyInjection`
* **JSON Persistence:** `System.Text.Json` for application settings
